# Rift Armada – glossary for the English translation

Rift Armada is a 2D space real-time strategy game for Android phones (Star Trek Armada 2 style, own universe).
German is the source language. Tone: crisp game UI English; radio messages and story texts read like good
military sci-fi dialogue (short sentences, characterful, not stiff). British spelling (armour, colour, centre,
defence, recognise) to match the developer's earlier game RTS – Rapid Tactical Strike.

## Rules
- Keep placeholders exactly: `{0}`, `{1}`, `{2}` (order may change if English grammar needs it).
- Keep HTML tags, `\n`, symbols (★ ◆ ⚒ ◎ ⬢ ✺ ⌘ · → ▸ ×) and numbers. Roman numerals stay (Level II).
- Numbers: `+15 %` → `+15%`, `2,5 %` → `2.5%`, decimal comma → point, `1.500` (thousands) → `1,500`.
- German quotes »…« → “…”. Keep the dash ` – ` as an en dash with spaces.
- German addresses players as "du" in the UI and "Sie" in radio; English simply uses "you".
- Proper names stay as they are: faction names (The Alliance, Martian Republic, Golden Legion, The Nexus,
  The Brood), ship class names that are already English (Lancer, Bulwark, Hedgehog, Paladin, Prism …), person
  names (Ilya Voss, Mara Kessler, Okafor, Seraph, Cassius, Prime Facet, K-7, Vex, Marr, Hale, Calder, Tarn, Varo),
  place names (Haven, Neu-Tharsis → New Tharsis, Aurum, Calder, Nera, Brask …). "Der Kern" (Nexus capital) → "The Core".
- If a string is already English or a pure proper name, return it unchanged.
- Fragments (e.g. a single word used as a button or label) get the shortest natural English label.
- Text that is a full sentence ends with the same punctuation.
